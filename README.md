# 扩充实验代码

本子项目是 DC-PSR / DC-PHSR 论文实验代码的**规范化重整版本**。它建立在仓库既有历史实验（`代码/`、`baselines/`、`experiments_mendeley/`、`final_five_seed_sweep/`、`protocol_diagnostic_fixed_preprocess/`、`final_statistical_evidence/`、`补充材料/小论文/`）之上，目标是：

1. 把散乱的历史实验资产整理成一个可审计、可复现、结构统一的目录；
2. 在此结构下启动"第一轮"规范化实验：仅 **B9 = DC-PHSR** 在 **PHM2010 D1** 上的严格 5-seed 训练。

## 重要约定

- **不修改任何旧代码原文件**。旧目录（见"旧代码来源"表）全部只读，本项目只复制/引用，不回写。
- **DC-PHSR = 论文新名称**；旧代码内部仍使用 `DC-PSR` / `B12` / `FGDS-PSI` 作为类名、变量名、脚本名 —— 本轮不做大范围重命名，README 中会交叉标注。
- 中文目录名（`扩充实验代码`、`01_主对比实验` 等）作为最外层结构保持不变。若 Python import 在中文路径下不稳定，内部包/模块使用英文名，映射关系见各子目录 README。
- 所有新结果只写入本目录（`扩充实验代码/`）下，不覆盖任何历史结果目录。
